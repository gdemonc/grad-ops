# Grad-Ops 规格说明（毕业项目）

## 背景

参考开源项目 OpsCouncil，为毕业设计实现一个**简化版**证据约束型自主运维控制平面。原项目约 300 个 Python 文件、134 个测试，不可作为毕业交付。本项目目标是保留其核心差异化能力，规模控制在可独立完成、可独立答辩的范围内。

## 已确认的约束

| 项 | 决定 |
| --- | --- |
| 代码位置 | 独立新目录 `grad-ops/`，不改原仓库 |
| 功能范围 | 核心闭环 |
| 存储 | FastAPI + SQLite（无外部数据库依赖） |
| 大模型 | 接真实 OpenAI 兼容 API，同时提供 Mock 供离线测试 |
| 周期 | 1 个月以上，需交付论文/报告 |
| 平台 | 开发机为 Windows，目标运行环境为 Linux；工具层需做平台适配 |

## 核心闭环（必须全部实现）

```
自然语言请求
  -> 任务入队
  -> 只读工具取证（写入 Evidence）
  -> LLM 调查（结论必须引用证据 ID）
  -> 生成动作契约（工具/参数/风险/前置/回滚/验证项）
  -> 确定性策略控制器校验（模型无权自授）
  -> 人工审批（R2/R3）
  -> 受限执行（路径白名单 + 风险等级 + 身份检查）
  -> 独立恢复验证（复用调查证据 = 无效）
  -> SHA-256 哈希审计链
```

## 必须具备的安全性质

1. **证据约束**：LLM 产出的每条结论声明必须绑定至少一个真实 Evidence ID；引用不存在证据的声明被丢弃并标记。
2. **策略外部化**：动作能否执行由确定性规则表决定，不由模型输出决定；R4 直接拒绝，拒绝时工具调用数为 0。
3. **有界执行**：副作用工具白名单 + 目标路径白名单 + 受保护路径黑名单 + 风险等级准入。
4. **审批门**：R2/R3 必须人工批准；批准令牌与契约摘要绑定，一次性使用，摘要不匹配则拒绝。
5. **验证独立性**：验证阶段用全新只读工具调用回读系统状态，禁止复用调查阶段证据。
6. **可审计**：所有事件形成哈希链，可校验、可重放、可检测篡改。

## 风险模型

| 等级 | 含义 | 处置 |
| --- | --- | --- |
| R0 | 只读观测 | 自动放行 |
| R1 | 可逆副作用 | 策略白名单内可自动，否则人工 |
| R2 | 需审批的副作用 | 人工审批后受限执行 |
| R3 | 高风险副作用 | 人工审批 + 受限身份 + 路径边界 |
| R4 | 危险/越权 | 直接拒绝，不进入工具执行 |

## 工具清单（7 项）

只读（5）：`list_listening_ports`、`list_processes`、`disk_usage`、`read_service_log`、`check_service_health`

副作用（2）：`backup_log_file`、`rotate_log_file`

## 交付物

- `grad-ops/` 可运行源码 + 测试（≥60 个用例）
- Vue 3 工作台：任务列表/详情、审批队列、审计校验、安全报告
- `docs/` 论文素材：架构图、时序图、威胁模型表、测试报告
- `README.md` 快速启动（Windows 与 Linux 两种说明）

## 明确不做

pgvector 知识库、5 角色多 Agent 编排、飞书通道、巡检调度、评测靶场、Docker 编排、systemd 生产加固。
