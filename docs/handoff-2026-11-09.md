## 当前一句话状态

Grad-Ops 的 Go + Linux 单机闭环已在 Ubuntu 26.04.1 LTS / Go 1.27.3 上通过构建、测试（含 `-race`）和端到端冒烟；LLM 客户端与两阶段计划器、AST 只读分析、prlimit 资源限制、可选 uid/gid 切换、API Bearer 认证、调查/执行时限和 hardened systemd 部署已实现。

仍未实现：per-action cgroup/namespace、文件系统与网络隔离、privileged broker、真实的 systemd 安装验证、Linux CI，以及真实 LLM provider 的密钥联调。
